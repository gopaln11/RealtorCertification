# 10. Later: Real Estate Economics or Accounting

A broker applicant must complete Real Estate Economics or Accounting. If both are completed, only two electives are required instead of three. Principles counts as an elective, so it is already one.

Before you pay for either course, check whether an old official transcript already has a 3-semester-unit or 4-quarter-unit Accounting or Economics course, with a catalog description DRE can evaluate. An MBA does not automatically equal either course. The requirements page says equivalent courses are evaluated from the transcript plus the official description. That check is the same one described in [02-real-estate-finance](../02-real-estate-finance/) for the salesperson elective. Foreign coursework uses RE 223, filed there.

Neither Economics nor Accounting is required to get the salesperson license. Do not take them now unless one of them is the transcript course you are using as the salesperson elective.

DRE does not publish a free economics or accounting course. No paid course was downloaded. The chapters below are from the 2010 Reference Book. Taxation and investment-vehicle vocabulary only. Not current tax law. For a current statute, use [shared-2026-real-estate-law](../shared-2026-real-estate-law/), and for tax advice use a tax adviser, not this folder.

The broker course list is [broker-requirements.md](../12-later-broker-license-and-exam/materials/broker-requirements.md).
