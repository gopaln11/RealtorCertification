# 9. Later: Real Estate Appraisal

Required for a broker license. Not required for the salesperson license. Valuation is still about 14 percent of the salesperson exam, so the ideas show up earlier, inside Principles, Finance, and exam prep. Do not take this as an extra course before you are licensed and working unless you choose Appraisal as the salesperson elective instead of Finance.

The broker course list is [broker-requirements.md](../12-later-broker-license-and-exam/materials/broker-requirements.md). The statutory Appraisal course has to be purchased. DRE does not give it away. No paid appraisal course, and no Appraisal Institute textbook, was downloaded.

The chapter here is from the 2010 Reference Book. It is a map of appraisal vocabulary. It is not current USPAP and it is not the statutory course. Current law, when a statute is the question, is in [shared-2026-real-estate-law](../shared-2026-real-estate-law/).
