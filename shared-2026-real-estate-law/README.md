# 2026 Real Estate Law

Shared lookup library for every course in this path. It is not a statutory course, and it is not a book to read before Principles.

DRE’s preparing-for-the-exam page points examinees to this set. Use it when a practice question turns on a current rule. The Reference Book chapters filed under the courses are copyright 2010 and are outdated for current law.

Retrieved October 2, 2026 from [2026 Real Estate Law](https://www.dre.ca.gov/publications/RealEstateLaw.html). The page says the book is statutes and regulations in effect January 1, 2026, and that it does not contain every California law that can touch a real estate transaction. The full codes are at [leginfo.legislature.ca.gov](https://leginfo.legislature.ca.gov/).

This is not legal advice.
